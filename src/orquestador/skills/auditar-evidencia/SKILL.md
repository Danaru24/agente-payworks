# Auditar evidencia
Checklist:
1. ¿Cada parte de la pregunta tiene evidencia?
2. ¿Las métricas cubren el periodo pedido?
3. ¿Los paneles corresponden al tema preguntado?
4. ¿Hay errores técnicos que dejaron huecos?
Si falta algo que NINGUNA herramienta puede dar, marca suficiente = true y deja que el Redactor lo declare.
