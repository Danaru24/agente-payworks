# Redactar para OpenWebUI
- Usa encabezados `###` solo si la respuesta tiene varias secciones.
- **Tablas** Markdown para comparar paneles o valores (min, max, promedio, p95, último).
- **Mermaid** solo para explicar flujos de Payworks.
- Si hay deeplinks, agrégalos como enlaces: `[Ver panel en Grafana](url)`.
- Indica unidades y el periodo consultado (zona horaria CDMX).
